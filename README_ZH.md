# 未知回响

> 仍在开发阶段，欢迎反馈问题。

> 走出去,聆听大地的回响,发现被遗忘的世界。

**未知回响**是一个以"探索 + 解谜 + Boss 战 + 渐进式能力成长"为核心的冒险类 Mod。

你将打开通往**回声境域**的大门,在第一维度的十个群系里追踪远古回声、破解古老机关、击败守护者,再深入第二维度的三片深层区域。五种"回响"之力、六件神器和新的装备路线会随着个人探索进度逐步展开。

---

## 快速开始

### 进入回声境域

1. **合成回声境域钥匙**:用**回响碎片 + 回响核心**合成一把*回声境域钥匙*。
2. **找到残响信标**:残响信标会在主世界自然生成(残响信标遗迹)。
3. **唤醒信标**:手持钥匙右键信标。
4. **进入回声境域**:右键已激活的信标。
5. **返回主世界**:在境域内右键信标即可回到主世界出生点/重生点。

### 进入深层回响

1. **完成回声境域主线**:获得风之回响、潮汐回响与真视回响，击败三名主线 Boss，并在回声峭壁的回声总档案馆完成三段档案试炼后操作档案终端。档案终端会把最近祭坛的线索写入探索日志。
2. **找到深渊信标祭坛**:祭坛会在回声峭壁群系自然生成。
3. **激活深层通道**:空手右键深渊信标，按风→潮汐→真视顺序完成三段校准；每段动画结束后再次右键。
4. **进入深层回响**:最终激活动画结束后，再次右键深渊信标进入深层回响。
5. **返回回声境域**:在裂层门厅右键深渊信标，返回回声境域。

---

## 核心玩法

1. 探索**回响森林**,找到记忆柱庭院,击败**遗忘巨像**,解锁**风之回响**。
2. 探索**镜湖 / 潮汐灯塔礁**,深入沉没圣殿,击败**深渊观测者**,解锁**潮汐回响**。
3. 探索**镜尘回廊**,攻入镜面神殿,击败**镜像守护者**,解锁**真视回响**。
4. 在第一维度的 10 个群系与第二维度的 3 个区域收集材料、远古残页和结构记录,挑战 8 个**区域守护者(Mini Boss)**。
5. 凭探索进度解锁并升级 6 件**核心神器**,强化五条能力路线。
6. 找到**回声峭壁**的大档案馆,达成完成度后领取个人毕业奖励与通往更深处的线索。

## Boss 与区域守护者

### 五大主线 Boss

每个主线 Boss 都有**破防机制**:未破防时硬抗高伤害,必须先用场地机关打开破防窗口才能造成有效伤害。

| 主线 Boss | 场地 | 解锁能力 |
|---|---|---|
| **遗忘巨像** | 记忆柱庭院(回响森林) | 风之回响 |
| **深渊观测者** | 沉没圣殿(镜湖/潮汐灯塔礁) | 潮汐回响 |
| **镜像守护者** | 镜面神殿(镜尘回廊) | 真视回响 |
| **虚空先知** | 校准大厅(倒悬裂谷) | 重力回响 |
| **裂隙看守者** | 虚空脉室(静默深渊) | 虚空回响 |

> **世界回响体** 集齐五种回响并完成终局条件后,在世界共鸣殿召唤它。（未完成）
