# 未知回响

**其他语言版本: [English](README.md) ｜ [中文](README_ZH.md)**

**下载: [Modrinth](https://modrinth.com/mod/unknown-echoes) ｜ [Curseforge](https://www.curseforge.com/minecraft/mc-mods/unknown-echoes)**

**未知回响**是一款围绕探索、解谜、首领战与能力成长展开的冒险模组。探索回声境域的十个群系，再深入深层回响的三层六群系；五种回响能力、六件神器与多条装备路线随个人进度解锁。

> 可以参照成就系统里的进度一步步游玩。按 **K** 打开回响总览。

> 提示：合金套为进入此模组维度的基准设计数值。可使用 **/unknownechoes** 指令进行测试。

> 建议搭配光影游玩，生物与方块都绘制了大量发光层。

## 快速开始

### 进入回声境域

1. **合成回声境域钥匙**：用 **4 枚回响碎片 + 1 枚回响核心**合成钥匙。
2. **找到残响信标**：残响信标遗迹会在主世界自然生成。
3. **唤醒信标**：手持钥匙右键信标。
4. **进入回声境域**：右键已激活的信标。
5. **返回主世界**：在境域内右键信标，返回主世界出生点或重生点。

### 进入深层回响

1. **完成回声境域主线**：获得风之回响、潮汐回响与真视回响，击败三名主线首领，并在回声总档案馆完成三段档案试炼。档案终端会把最近祭坛的线索写入探索日志。
2. **找到深渊信标祭坛**：祭坛会在回声峭壁自然生成。
3. **激活深层通道**：空手右键深渊信标，按风→潮汐→真视的顺序完成三段校准；每段动画结束后再次右键。
4. **进入深层回响**：最终激活动画结束后，再次右键信标。
5. **返回回声境域**：在裂层门厅右键深渊信标。

## 核心玩法

1. 探索**回响森林**，找到记忆柱庭院，击败**遗忘巨像**，解锁**风之回响**。
2. 探索**镜湖与潮汐灯塔礁**，深入沉没圣殿，击败**深渊观测者**，解锁**潮汐回响**。
3. 探索**镜尘回廊**，进入镜面神殿，击败**镜像守护者**，解锁**真视回响**。
4. 探索回声境域与深层回响的 16 个群系，收集材料、远古残页和遗迹记录，挑战 10 名**区域守护者**。
5. 凭探索进度解锁并升级 6 件**核心神器**，强化五条能力路线。
6. 在**回声峭壁**找到回声总档案馆，完成主线归档并显现深层线索。
